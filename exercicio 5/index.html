Aula 09 - Wireframe e Planejamento de Leiautes

Um wireframe é um rascunho da estrutura de uma página web. Ele mostra onde cada elemento vai ficar, como o cabeçalho, o menu, o conteúdo principal, a barra lateral e o rodapé.

Ele é importante porque ajuda a organizar a página, pensar na hierarquia das informações e facilitar a comunicação antes da programação.

Exemplo de wireframe

+------------------------------------------------------+
| LOGO        HOME    POSTS    SOBRE    CONTATO       |
+------------------------------------------------------+
|                                                      |
|                 TÍTULO PRINCIPAL                     |
|         Texto de apresentação do blog               |
|                                                      |
+------------------------------------------------------+
| POST 1 | POST 2 | POST 3                            |
| resumo | resumo | resumo                            |
+------------------------------------------------------+
| MAIS LIDOS / LINKS / NEWSLETTER                     |
+------------------------------------------------------+
| COPYRIGHT        REDES SOCIAIS        CONTATO      |
+------------------------------------------------------+

A relação com o HTML é direta:

  • cabeçalho = header
  • menu = nav
  • conteúdo principal = main
  • post = article
  • barra lateral = aside
  • rodapé = footer

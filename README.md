# GameZone

## Descrição do Projeto

O GameZone é um blog temático sobre jogos, criado como projeto do curso Técnico em Desenvolvimento de Sistemas.

O site tem como objetivo apresentar conteúdos relacionados ao universo dos videogames, como notícias, curiosidades, recomendações, lançamentos e informações sobre diferentes jogos e plataformas.

O projeto contará com páginas interligadas por um menu de navegação e será desenvolvido utilizando HTML e CSS.

## Estrutura Analítica do Projeto - EAP

O projeto foi dividido em três módulos principais.

### 1. Planejamento e Documentação

- Revisar os requisitos do projeto
- Organizar a estrutura das páginas
- Definir o conteúdo das páginas
- Atualizar o README.md

### 2. Desenvolvimento Front-End

- Criar a página index.html
- Criar a página posts.html
- Criar a página sobre.html
- Criar e aplicar o style.css

### 3. Testes e Finalização

- Testar a navegação entre as páginas
- Testar o layout e o conteúdo
- Corrigir erros encontrados
- Registrar as alterações com Git
